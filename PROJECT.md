# Proyecto Backstage

## Objetivo

Construir una aplicación fullstack para gestionar la producción de eventos
y practicar frontend, backend, pruebas, contenedores y despliegues.

## Alcance funcional previsto

- Eventos y su información operativa.
- Tareas y responsables.
- Incidencias y preparación del evento.
- Comentarios, auditoría y dashboard.
- Autenticación y autorización.
- Webhooks firmados e idempotentes.

## Tecnologías

TypeScript, Next.js, React, NestJS, Fastify, PostgreSQL, Python,
Flask, pnpm, Turborepo, Docker, Jenkins, Kubernetes, Auth0, GCP y Terraform.

## Metodología

Cada paso incluye conceptos, implementación, pruebas, documentación
y commits por avance o funcionalidad.

Solo se registra como validado lo ejecutado y comprobado.
Las correcciones se entregan con archivos completos.

## Condiciones de trabajo

Desarrollo desde Ubuntu y ejecución en Docker.
Pruebas del frontend, backend y servicio Python.
Verificaciones secuenciales para cuidar la memoria del equipo.

La nube comienza después de validar la aplicación local.
Se revisarán gratuidad y costos antes de desplegar.

## Identidad visual

Universo de producción musical y operación detrás del escenario.
Interfaz oscura, jerarquía clara y acentos expresivos.
El branding se desarrollará junto con las pantallas funcionales.
